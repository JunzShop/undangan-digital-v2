## 🚀 Cara Deploy ke Netlify

### **Option 1: Drag & Drop (TERMUDAH)**

1. **Buka Netlify**
   - https://app.netlify.com/drop

2. **Drag folder `undangan-digital`**
   - Drag seluruh folder ke area upload
   - Tunggu 30-60 detik

3. **Dapatkan URL**
   - Netlify akan kasih URL seperti: `https://random-name-123.netlify.app`
   - Bisa custom domain name

4. **Selesai!** 🎉
   - Landing page sudah live
   - Bisa langsung dipakai untuk marketing

---

### **Option 2: Netlify CLI (Advanced)**

```bash
# Install Netlify CLI
npm install -g netlify-cli

# Login
netlify login

# Deploy
cd ~/undangan-digital
netlify deploy --prod
```
